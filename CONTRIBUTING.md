# Contributing

Thanks for your interest in improving Chromium Kiosk Starter.

1. Open an issue before proposing major changes.
2. Keep the project white-label and compatible with X11.
3. Do not commit secrets, production domains, personal IP addresses or browser profiles.
4. Run `bash -n kiosk.sh scripts/*.sh` and describe how you tested your change.
5. Submit a focused pull request with a clear description.

Please be respectful and constructive in issues and reviews.
